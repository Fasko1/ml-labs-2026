## Зафиксированные разбиения

Архив `fixed_splits.zip`, полученный из Colab, проверен и распакован в
`splits/`. Контрольные суммы исходных CSV совпали с `manifest.json`.
Проверены уникальность номеров строк и отсутствие пересечений групп.

| Данные | Train | Test | Доля теста |
| --- | ---: | ---: | ---: |
| Страховка | 1543 | 444 | 22.3% |
| Ноутбуки | 1009 | 266 | 20.9% |

Для страховки использована первая часть StratifiedGroupKFold из пяти,
shuffle=True, random_state=42. Для ноутбуков — GroupShuffleSplit с
test_size=0.2, random_state=42 (доля относится к числу групп).
Группы образованы по всем выбранным входным признакам без цели.
Из регрессионных входов исключены Product, CPU_model и GPU_model.
Списки входных столбцов и версии библиотек находятся в `splits/manifest.json`.
При чтении разбиений `row_position` следует применять через iloc к исходному
CSV с тем же порядком строк; контрольные суммы должны совпадать.

Доли классов страховки: train — 63.77%/36.23%,
test — 65.99%/34.01% для классов 0/1 соответственно. Повторный выбор seed
или теста на основании качества моделей не выполняется.

## Первичное исследование train

Для 1009 ноутбуков обучающей части средняя цена составляет
1148.83 евро, медиана 989.00 евро, минимум 191.90 евро, максимум 6099.00 евро;
квартили 614.00 и 1499.00 евро, 95-й процентиль 2481.94 евро.
У распределения цены длинный правый хвост. Поэтому в ЛР1 проверено
преобразование log1p цены. При выбранных параметрах KNN оно не уменьшило
MAE на CV и не вошло в итоговую модель. Дорогие ноутбуки сохранены в данных.
