# Исследование алгоритмов машинного обучения

В репозитории собраны лабораторные по машинному обучению. Для классификации
используется покупка туристической страховки, для регрессии — цена ноутбука.
Во всех работах остаются одни и те же данные и разбиения.
Сравниваются библиотечные модели и собственные реализации до и после улучшений.

## Состояние проекта

- [ЛР1 — KNN](lab1_knn.ipynb): готова. Ноутбук повторно выполнен в новой
  среде Colab: все 15 кодовых ячеек прошли без ошибок, результаты повторились.
- ЛР2 — линейная и логистическая регрессия: следующий этап.
- ЛР3 — решающее дерево: запланирована.
- ЛР4 — случайный лес: запланирована.
- ЛР5 — градиентный бустинг: запланирована.
- Отдельный итоговый ноутбук: будет подготовлен после пяти работ.

## Практические задачи и данные

| Задача | Источник | Цель | Размер исходного CSV |
| --- | --- | --- | --- |
| Выбор клиентов для предложения туристической страховки | [Travel Insurance Prediction Data](https://www.kaggle.com/datasets/tejashvi14/travel-insurance-prediction-data) | `TravelInsurance`, 0/1 | 1987 строк, 10 столбцов с техническим индексом |
| Оценка цены ноутбука по его характеристикам | [Laptop Prices](https://www.kaggle.com/datasets/owm4096/laptop-prices) | `Price_euros` | 1275 строк, 23 столбца |

Цены ноутбуков взяты из исходного набора и могут отличаться от нынешних цен
магазинов. В задаче страховки предсказывается покупка полиса.
Оба набора внесены в общую таблицу курса.

Исходные файлы находятся в `data/raw/`, контрольные суммы и описание —
в [data/README.md](data/README.md). Служебный индекс страховки исключён
из входов. Из регрессии исключены `Product`, `CPU_model`, `GPU_model`
для ограничения числа редких категорий; остаётся 19 входных столбцов.

## Протокол экспериментов

Строки с одинаковыми входными признаками объединены в группы. По данным
нельзя установить, относятся ли такие строки к одному клиенту, поэтому
повторы и строки с разными ответами сохранены. Для проверки на новых
сочетаниях характеристик каждая группа целиком отнесена к train или test.
Группы также учитываются внутри CV.

| Данные | Train | Test | Разбиение |
| --- | ---: | ---: | --- |
| Страховка | 1543 | 444 | Первая часть StratifiedGroupKFold, 5 частей, shuffle=True, random_state=42 |
| Ноутбуки | 1009 | 266 | GroupShuffleSplit, test_size=0.2 по группам, random_state=42 |

Разбиения train/test, номера валидационных частей CV и параметры сохранены
в `data/splits/`. Подбор параметров выполнен на трёхчастной групповой CV
обучающей части. Предобработка обучается внутри Pipeline. Отложенный тест
использован после выбора вариантов. Для следующих работ сохраняются те же
исходные строки, train/test и части CV.

Основные метрики: macro-F1 для классификации (равный вклад обоих классов)
и MAE для регрессии (средняя абсолютная ошибка в евро).
Дополнительно: Accuracy, ROC-AUC, Precision/Recall и матрицы ошибок;
RMSE для крупных ошибок и R² для регрессии.

## Результаты ЛР1 на отложенном тесте

| Классификация | Macro-F1 | Accuracy | ROC-AUC |
| --- | ---: | ---: | ---: |
| sklearn baseline | 0.7221 | 0.7658 | 0.7555 |
| sklearn improved | 0.7233 | 0.7658 | 0.7575 |
| own baseline | 0.7179 | 0.7613 | 0.7547 |
| own improved | 0.7191 | 0.7613 | 0.7544 |

| Регрессия | MAE, евро | RMSE, евро | R² |
| --- | ---: | ---: | ---: |
| sklearn baseline | 237.2231 | 366.2704 | 0.7099 |
| sklearn improved | 196.2581 | 305.6349 | 0.7980 |
| own baseline | 237.7397 | 366.8557 | 0.7090 |
| own improved | 196.1175 | 305.5828 | 0.7981 |

Исходные параметры KNN: k=5, uniform, p=2, без масштабирования числовых
признаков; категории кодируются one-hot. Улучшенная классификация:
k=5, distance, p=2, без масштабирования. Улучшенная регрессия: k=5,
distance, p=1, StandardScaler. PPI и log1p цены проверены на CV, но при
выбранных настройках не уменьшили MAE и не включены в итоговую модель.

Качество собственного KNN близко к sklearn. В классификации прирост macro-F1
небольшой, найдено около 55% покупателей. В регрессии остаются большие ошибки
на отдельных дорогих ноутбуках. Время измерено за один запуск в Colab;
для сравнения скорости в других условиях нужны отдельные измерения.

Полные значения, индивидуальные прогнозы, параметры и графики — в `results/`.
Записи об экспериментах — в [EXPERIMENT_LOG.md](EXPERIMENT_LOG.md).
CSV в `results/` относятся к первому выгруженному запуску; рабочий ноутбук
содержит контрольный повтор. Качество совпало до отображаемой точности,
три графика совпали; измеренное время отличается между запусками.
Отчёт сравнения сохранён в [docs/LAB1_RERUN.json](docs/LAB1_RERUN.json).

## Запуск в Google Colab

1. Открыть `lab1_knn.ipynb` в Colab через загрузку ноутбука.
2. Выбрать Python 3 и CPU.
3. Для контрольного запуска отключить и удалить текущую среду выполнения,
   подключиться к новой и выполнить все ячейки по порядку.
4. При запросе выбрать оба исходных CSV из `data/raw/`. Сохранить их исходные
   имена, указанные в ноутбуке.
5. Дождаться завершения, убедиться в отсутствии ошибок. Ноутбук создаёт
   таблицы и рисунки в `/content/results`, а разбиения — в `/content/data/splits`.
6. Сохранить `.ipynb` с выводами и скачать `lab1_artifacts.zip`.

Ноутбук содержит реализацию KNN полностью, импорт `src/knn.py` для запуска
в Colab не требуется. Модуль в `src/` — дополнительная копия для переиспользования.
Файлы `colab_*.py` содержат код оценки и сохранения результатов;
этот код также включён в ноутбук.

Версии использованного окружения записаны в `requirements.txt` и
`results/lab1_settings.json`; Python в первом запуске — 3.13.18.
Colab показывает фактические версии первой кодовой ячейкой. Текущая инструкция
рассчитана на Colab: загрузка и скачивание файлов используют `google.colab`.
