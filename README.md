## Данные

- [Travel Insurance Prediction Data](https://www.kaggle.com/datasets/tejashvi14/travel-insurance-prediction-data): прогноз покупки страховки по характеристикам клиента. Цель — `TravelInsurance`, 0 или 1. Такой прогноз может помочь выбрать клиентов для предложения полиса.
- [Laptop Prices](https://www.kaggle.com/datasets/owm4096/laptop-prices): оценка цены ноутбука по его характеристикам. Цель — `Price_euros`. Цены относятся к исходному набору и могут отличаться от нынешних цен магазинов.

Эти наборы используются во всех работах. Разбиения train/test фиксированы,
одинаковые входные профили объединены в группы. Параметры выбираются на
групповой кросс-валидации обучающей части. Код подготовки данных,
собственные алгоритмы, результаты и пояснения находятся в ноутбуках.

## Запуск в Google Colab

1. Открыть нужный файл `.ipynb` в Google Colab.
2. Выбрать Python 3 и CPU.
3. Скачать оба набора по ссылкам выше и распаковать архивы.
4. Нажать «Выполнить все». При запросе загрузить оба CSV:
   `TravelInsurancePrediction.csv` и `laptop_prices.csv`.
5. Дождаться завершения всех ячеек. Первая ячейка выводит версии библиотек.

Ноутбуки содержат полный код. Графики и таблицы сохранены в выводах.
При запуске также создаются CSV результатов и архив для скачивания.

Итоговый `lab6_summary.ipynb` запускается отдельно: CSV метрик ЛР1–5
уже встроены в него. Загружать исходные данные и обучать модели
для построения итоговых таблиц и графиков не требуется.
