## Выполненные проверки

- Корректный JSON формата ipynb 4; в рабочей версии 33 ячейки, из них 15
  кодовых, с execution_count 1–15. Ошибок в сохранённых outputs нет.
- Сохранены три изображения: исследование train, матрицы ошибок и графики
  регрессии. В отдельные PNG экспортированы два последних рисунка.
- У каждой кодовой ячейки есть комментарии или поясняющий docstring;
  этапы исследования сопровождаются Markdown.
- Код KNN, финальной оценки и выгрузки совпадает с соответствующими `.py`.
- Контрольные суммы обоих CSV совпадают с исходным manifest.
- Каждая исходная строка встречается ровно один раз в train/test-разбиении.
- У одинаковых выбранных входных профилей один group_id. Группа не попадает
  одновременно в train и test. Проверены 1102 группы страховки и 1192 группы
  ноутбуков после выбранного исключения столбцов.
- Все обучающие строки представлены в таблицах CV ровно один раз как
  валидационные; одна группа относится к одной из трёх частей CV.
- Тестовые row_position и истинные ответы в прогнозах соответствуют
  исходным CSV и сохранённым разбиениям.
- Из индивидуальных прогнозов независимо пересчитаны Accuracy, macro-F1,
  ROC-AUC, Precision/Recall, MAE, RMSE и R² для всех восьми моделей.
  Значения совпали с CSV результатов с абсолютным допуском 1e-10.
- Числа TN/FP/FN/TP пересчитаны и совпали с отдельной таблицей матриц ошибок.

Независимый расчёт выполнен командой `node docs/verify_lab1.mjs` из корня
всего проекта. Использованы сохранённые прогнозы; ML-модели этим скриптом
не обучаются. Для допустимых численных ошибок вероятностей используется
допуск 1e-12: при нормировке весов сумма может отличаться от 1 на величину
порядка машинной точности.
